# 🤖 AI 기반 자동 파일 정리 시스템 v2.0

코딩 지식이 없는 일반 사용자도 쉽게 사용할 수 있는 프로덕션 레벨 파일 자동 정리 시스템입니다.

## ✨ 핵심 기능

### 🎯 사용자 친화적
- ✅ **원클릭 설치**: Python 자동 확인 및 의존성 자동 설치
- 🖱️ **GUI 폴더 선택**: 마우스로 쉽게 폴더 선택
- 👀 **실행 전 미리보기**: 어떤 파일이 어디로 이동할지 미리 확인
- 📊 **실시간 진행 바**: 현재 처리 현황을 실시간으로 표시
- 💬 **이모지 + 한글 메시지**: 쉽게 이해할 수 있는 친근한 메시지

### 🛡️ 안전 장치
- 🔒 **중요 파일 보호**: 실행 파일(.exe), 시스템 파일 자동 제외
- 📦 **대용량 파일 경고**: 100MB 이상 파일 처리 시 확인 요청
- 📈 **파일 수 제한**: 500개 이상 처리 시 경고
- 👻 **숨김 파일 보호**: 숨김 파일 자동 제외 옵션
- ↩️ **언제든지 복원**: 모든 작업을 쉽게 되돌릴 수 있음

### 🎨 스마트 분류
- 🏷️ **지능형 분류**: 파일명, 메타데이터, OCR 기반 자동 분류
- 📝 **원본 파일명 보존**: `[카테고리]_[기존파일명]` 형식
- 📊 **실시간 대시보드**: 웹 기반 모니터링 및 통계
- 📋 **상세 로깅**: 모든 작업 JSON 형식으로 기록

## 🚀 빠른 시작

### 1단계: 설치 (1분)

**우클릭** → **관리자 권한으로 실행**:
```
🚀 자동설치.bat
```

### 2단계: 실행 (10초)

바탕화면의 바로가기를 더블클릭:
```
📁 폴더선택_정리
```

### 3단계: 완료!

1. 정리할 폴더 선택
2. 미리보기 확인
3. 'y' 입력하여 시작

---

## ⚙️ 설정 변경 (선택사항)

`config.json` 파일을 메모장으로 열어 수정:

```json
{
  "safety": {
    "large_file_threshold_mb": 100,    // 대용량 파일 기준
    "max_files_warning": 500,          // 파일 수 경고
    "protect_hidden_files": true       // 숨김 파일 보호
  },
  "processing": {
    "enable_ocr": false,               // OCR 기능 (이미지 텍스트 추출)
    "show_progress": true,             // 진행 바 표시
    "preview_before_execute": true     // 실행 전 미리보기
  },
  "ui": {
    "use_emoji": true,                 // 이모지 사용
    "verbose_mode": false              // 상세 모드
  }
}
```

## 📖 사용 예시

### GUI 모드 (추천)
```bash
python src/main.py
```
→ 폴더 선택 창이 나타나고, 미리보기 후 실행

### 명령어 모드
```bash
# 특정 폴더 지정
python src/main.py --target "C:\Users\Downloads"

# 테스트 모드 (실제 이동 안 함)
python src/main.py --dry-run

# 자동 모드 (Desktop을 확인 없이 정리)
python src/main.py --auto
```

## ❓ 자주 묻는 질문 (FAQ)

### Q1. 파일이 삭제되나요?
**A.** 아니요! 파일은 절대 삭제되지 않고 **이동**만 합니다.

### Q2. 잘못 정리된 파일을 되돌릴 수 있나요?
**A.** 네! 모든 작업이 로그로 기록되며, 롤백으로 원래 위치로 복원할 수 있습니다.

### Q3. 특정 파일을 제외하려면?
**A.** `config.json`의 `exclude_extensions`에 확장자를 추가하세요.
